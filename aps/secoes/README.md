# Seções do documento

Um arquivo por item da WBS: `1.1.md`, `1.2.md`, …, `2.8.md`.
Cada autor edita **apenas** o arquivo do seu item, em branch própria (`item/<id>-<slug>`), e abre PR com `Closes #<issue>`.
O esboço completo atual está em `../documento/esboco-aps.md`. Copie dele o trecho do seu item como ponto de partida.
