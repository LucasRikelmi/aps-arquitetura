- Cada um dos 14 UCs aponta para pelo menos uma tela: atendido (Tabela 2).
- Toda tela TL aponta para um UC: atendido para TL-02 a TL-16. TL-01 (precondição de todos) e TL-17 (extensão *a) não apontam para um UC próprio. Registrar no texto final que são telas transversais.
